## 概要

RPGツクールVX/VXAceのキャラチップ素材をRPG Developer Bakinか異世界の創造者のキャラチップに変換するツールです。
本ツールはOpenCVを利用しています。
Windowsのネイティブウィンドウで動作するGUIアプリです。

## 使い方

コンパイル済みのツールは`bin` に保存済みです。

1. `CharachipConverter.exe` を起動します
2. 「入力フォルダ」に変換したいキャラチップが入ったフォルダを指定します（初期値: `.\input`）
3. 「出力フォルダ」に変換後のキャラチップを出力するフォルダを指定します（初期値: `.\output`。存在しない場合は自動作成されます）
4. 変換モードを選択します
  - 異世界の創造者
  - RPG Developer Bakin
  - 異世界の創造者 フェイス
5. 「変換開始」ボタンを押すと変換が実行され、結果がログ欄に表示されます

## 注意事項

- 本アプリを利用したことによる損失等は一切保証しません
- RPG Developer Bakin及び異世界の創造者と本ツール作者は無関係です
